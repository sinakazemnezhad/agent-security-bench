# Contributing

1. Keep checks deterministic and receipt-backed.
2. Do not weaken security cases to inflate pass rates.
3. Add tasks under `tasks/ml/` with stable `ml.*` ids.
4. Add suites under `security/suites/`.
5. Run `asb list` and the GitHub `validate` workflow locally before opening a PR.
6. Keep proprietary company runtimes out of this repository.

Related Persian/ML catalog work lives in [persian-llm-reference](https://github.com/sinakazemnezhad/persian-llm-reference).
